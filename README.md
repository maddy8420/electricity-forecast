# India Electricity Demand, Generation & Energy Mix Forecast

Time-series analysis and forecasting of India's electricity demand and
generation (2013-2024), used to project the demand-supply gap through 2040
and evaluate future energy-mix scenarios.

![Demand-Supply Gap](figures/demand_supply_gap.png)

## Key Finding

Central estimates show generation modestly outpacing demand through 2040
(+405 MU/day surplus in 2026, growing to +858 MU/day by 2040), though the
95% confidence band widens substantially at longer horizons — a genuine
data-driven surplus at the trend level, not a certainty at the tail. See
[`data_integrity_and_findings.md`](data_integrity_and_findings.md) for the
full methodology writeup, including a documented audit trail of three data
quality issues found and corrected during development.

## Excel workbook guide

The files in the project root are mostly generated pipeline outputs. The two
workbooks under `data/` are input data. “Created by” identifies the Python
script that writes the workbook; input workbooks were supplied as source data
and are not generated by this project.

| Workbook | What it contains / why it exists | Created by | Used by |
|---|---|---|---|
| `data/hourlyLoadDataIndia.xlsx` | Raw hourly national and regional load data | External source data | `consolidate_data_v2.py` |
| `data/monthly_temp.xlsx` | Raw monthly temperature data | External source data | `consolidate_data_v2.py` |
| `india_electricity_master.xlsx` | Consolidated source data and analysis-ready sheets, including `MASTER_monthly` | `consolidate_data_v2.py` | `eda_analysis.py`, `feature_engineering.py`, `source_forecast.py`, `dashboard.py`, and scripts in `diagnostics/` |
| `india_electricity_master_new.xlsx` | Backup-named copy of the master workbook, written only if the main workbook is locked/open in Excel | `consolidate_data_v2.py` | No script reads this filename automatically; rename/copy it to `india_electricity_master.xlsx` before using it |
| `india_electricity_features.xlsx` | The monthly master data with forecasting features | `feature_engineering.py` | `forecast_models.py`, `forecast_multihorizon.py`, `sarima_order_search.py`, and `final_forecast.py` |
| `model_comparison_results.xlsx` | Model-comparison scores | `forecast_models.py` | Standalone evaluation results; no later script reads it |
| `multi_horizon_results.xlsx` | Walk-forward forecast scores at several horizons | `forecast_multihorizon.py` | Standalone evaluation results; no later script reads it |
| `sarima_order_search.xlsx` | Candidate SARIMA orders and search scores | `sarima_order_search.py` | Used to review/select an order; `final_forecast.py` currently has its order configured in the script |
| `avg_daily_demand_forecast_2040.xlsx` | Demand forecast with confidence intervals and validated-horizon flags | `final_forecast.py` (run with `TARGET_COL = "avg_daily_demand"`) | `demand_supply_gap.py`, `dashboard.py`, and `cea_benchmark.py` |
| `avg_daily_generation_forecast_2040.xlsx` | Generation forecast with confidence intervals and validated-horizon flags | `final_forecast.py` (run with `TARGET_COL = "avg_daily_generation"`) | `demand_supply_gap.py` and `dashboard.py` |
| `demand_supply_gap.xlsx` | Combined demand and generation forecasts, including their gap | `demand_supply_gap.py` | `dashboard.py` |
| `source_forecasts_2040.xlsx` | Historical and forecast values by generation source (`history` and `forecast` sheets) | `source_forecast.py` | `dashboard.py` (Mix Builder tab) |
| `cea_benchmark_comparison.xlsx` | Comparison of the demand forecast with official CEA benchmarks | `cea_benchmark.py` | Standalone comparison results; no later script reads it |
| `india_electricity_data.xlsx` (optional; not currently present) | Workbook from a separate diagnostic data pipeline | `diagnostics/data_pipeline.py` | Standalone diagnostic output; no later script reads it |

Typical order: `consolidate_data_v2.py` → `feature_engineering.py` →
`final_forecast.py` (run once for demand and once for generation) →
`demand_supply_gap.py` → `streamlit run dashboard.py`. The model evaluation,
SARIMA search, source-mix forecast, and CEA benchmark scripts create additional
workbooks for their respective analyses. The dashboard needs the main master,
demand forecast, generation forecast, and gap workbooks; the Mix Builder tab
also uses `source_forecasts_2040.xlsx`.

## Data Sources

- CEA Daily Power Generation by Source (2013-2023)
- CEA/Grid India Daily State-wise Demand & Energy Met (2015-2023)
- Hourly National + Regional Load, Grid India/RLDC (2019-2024)
- State-wise Electricity Consumption (2013-2024)
- Monthly Temperature data (2019-2021)

## Methodology Highlights

- **Walk-forward validation**, not a single train/test split — models are
  evaluated across many points in time and at multiple forecast horizons
  (1, 3, 6, 12, 24 months) before being trusted for a 2040 forecast.
- **Three data quality issues found and fixed** during development: a
  source-category double-counting bug, a ~5-month reporting blackout at a
  CEA format-transition boundary, and uneven monthly day-coverage that was
  silently producing false 600%+ growth spikes. Full details in
  [`data_integrity_and_findings.md`](data_integrity_and_findings.md).
- **Explicit validated-vs-extrapolated framing**: only the first 24 months
  of any forecast are empirically validated; everything beyond that is
  presented as a trend-based scenario, not a precise prediction — visible
  directly in the forecast charts and the dashboard.

## Running the pipeline

```bash
pip install -r requirements.txt

python consolidate_data_v2.py
python feature_engineering.py
python sarima_order_search.py          # confirms/updates the SARIMA order used below
python final_forecast.py               # set TARGET_COL to "avg_daily_demand" or "avg_daily_generation"
python demand_supply_gap.py
streamlit run dashboard.py
```

## Limitations

- Forecasts beyond ~2-3 years are trend extrapolations from ~11 years of
  monthly data — treat 2035/2040 figures as scenario projections, not
  precise predictions.
- Coal/Nuclear/Gas cannot be individually itemized before mid-2017 in the
  source data (see `data_integrity_and_findings.md`).
- The demand-supply gap's "worst case" currently treats demand and
  generation uncertainty as independent, which likely overstates the true
  worst case since the two series move together historically.
